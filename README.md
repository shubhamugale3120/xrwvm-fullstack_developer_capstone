# IBM Full Stack Developer Capstone — Car Dealership Application

**Repository Name:** xrwvm-fullstack_developer_capstone

**Project Name:** IBM Full Stack Developer Capstone — Car Dealership Application

## Project Overview

This project is a full-stack car dealership application for browsing dealerships, viewing dealership details, registering and logging in, and submitting dealership reviews.

## Technologies

- React and JavaScript
- Python and Django
- Node.js and Express
- MongoDB
- Flask and NLTK for sentiment analysis
- GitHub Actions
- IBM Cloud Code Engine
